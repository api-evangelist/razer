# Razer

> Razer is a global lifestyle brand for gamers, designing gaming hardware, software and services. For developers Razer operates the WYVRN immersive gaming platform, exposing the Razer Chroma RGB SDK and REST API, the Sensa HD Haptics and THX Spatial Audio SDKs, Razer ID sign-in, and the Razer Gold / Razer Silver virtual-currency payment and rewards APIs.

This llms.txt was generated by the API Evangelist enrichment pipeline from the apis.yml catalog and repo artifacts.

## APIs

- [Razer Chroma RGB REST API](https://assets.razerzone.com/dev_portal/REST/html/index.html): Control 16.8M-color RGB lighting across Chroma keyboards, mice, headsets, mousepads, keypads and ChromaLink devices. Base URL https://chromasdk.io:54236/razer/chromasdk (also localhost:54235).
- [Razer Gold API](https://developer.razer.com/razer-gold-developer-and-partner-program): Virtual-currency payment API for monetizing games and apps across 19 currencies with fraud/chargeback protection. Docs https://api.razer.com/docs.

## Developer programs

- [Razer ID](https://developer.razer.com/razerid): User sign-in / single sign-on for verified Razer users.
- [Razer Silver](https://developer.razer.com/razer-silver-developer-and-partner-program): Loyalty and rewards program tied to Razer Gold transactions.
- [WYVRN platform](https://www.wyvrn.com/): Chroma RGB, Sensa HD Haptics and THX Spatial Audio SDKs for Unity and Unreal.

## SDKs

- [HTML5ChromaSDK](https://github.com/razerofficial/HTML5ChromaSDK): JavaScript Chroma animation library.
- [Unity_WyvrnSDK](https://github.com/WyvrnOfficial/Unity_WyvrnSDK): WYVRN Unity SDK.
- [Unreal_WyvrnSDK](https://github.com/WyvrnOfficial/Unreal_WyvrnSDK): WYVRN Unreal Engine SDK.
- [Interhaptics_Unity_CoreSDK](https://github.com/WyvrnOfficial/Interhaptics_Unity_CoreSDK): Sensa HD Haptics core SDK.
- [AIKit](https://github.com/razerofficial/AIKit): Razer AI development toolkit (Python).
